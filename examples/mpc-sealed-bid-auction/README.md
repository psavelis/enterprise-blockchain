# MPC Sealed-Bid Auction

Models a sealed-bid procurement auction where three suppliers submit secret-shared bids and a demo harness reconstructs totals to select the lowest bid.

## What it demonstrates

- Additive secret sharing across competing parties.
- Secret-shared bid submission with integrity verification.
- Integrity verification via SHA-256 commitments.

## Run

```bash
npm run example:mpc-auction
```
